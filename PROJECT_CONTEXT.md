# FlowX

FlowX is an intelligent urban mobility and traffic distribution platform.

Goal:
Instead of always recommending the fastest route, intelligently distribute vehicles across multiple routes to reduce congestion.

Tech Stack

Frontend
- React
- Vite
- Tailwind CSS
- MapLibre
- OpenStreetMap

Backend
- Node.js
- Express

Database
- MongoDB Atlas

APIs
- OpenWeather
- TomTom Traffic API

Main Features

- Source and Destination
- Vehicle Type
- Route Preference
- Multiple Routes
- Balanced Routing
- Walking Safety
- Community Reports
- Weather
- Traffic
